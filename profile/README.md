<p align="center">Find the right kite spot in seconds.</p>
<p align="center"><a href="https://www.gustly.org">gustly.org</a> · Org profile · <a href="https://www.gustly.org/download">Download</a></p>
<p align="center">Where to go, when, with which kite. One honest call.</p>

---

Gustly takes the thinking out of a kite day. Ask in chat, tap a spot, or drop a pin anywhere on the map, and you get one verdict:

| | |
| --- | --- |
| 🟢 **SEND IT** | The wind is there, your kite fits, go. |
| 🟡 **SOFT CALL** | Rideable, with a catch. Gustly tells you which. |
| 🔴 **SIT IT OUT** | Stay home. Better a straight no than a fake calm. |

**What's inside**

- 💬 **Chat** that knows kiting: spot, wind window, kite size, wetsuit, shore direction.
- 🗺️ **Live wind map**: short dashes along the real wind, longer and warmer as it picks up. Every kite spot on Earth.
- 📈 **72 h forecast** per spot, blended from global and national weather models.
- 🧑‍💻 **CLI and MCP server** (`gustly-cli`), so your own agent gets the same forecasts.

**Honest data only.** No invented wind, gusts, tides or water temps. If it's missing, Gustly says so.
